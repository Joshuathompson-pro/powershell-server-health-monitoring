# Contributing

Small, focused improvements are welcome. Please keep examples synthetic and vendor-neutral.

1. Create a branch for the change.
2. Run the demo with `pwsh -File ./samples/Run-Demo.ps1`.
3. Run the Pester tests when Pester 5 is available.
4. Confirm no generated reports, real hostnames, credentials, or private logs are staged.
5. Open a pull request describing the operational problem the change solves.
